# 상품명 매출 수량
정산 · 순이익
마켓별 정산 연결 상태

매출은 카페24 주문 기준(취소 제외 실결제금액)입니다. 정산액·수수료는 마켓 정산 데이터가 연결되면 채워지고, 매출과 정산액이 안 맞는 건은 차이에 표시됩니다.

마켓정산 받는 방법매출정산액수수료차이
주문 대조

정산 데이터가 들어오면 우리 주문·배송·클레임(취소·반품·교환·환불) 기록과 주문번호로 맞춰 봅니다. 정산에서 빠진 주문, 금액이 다른 주문, 환불이 차감되지 않은 주문을 여기에 모아 보여 드립니다.

쿠팡부터 연결 예정입니다.
사업자별 순이익

순이익 = 매출 − 마켓 수수료 − 도매 원가 − 광고비 − 배송비. 아직 연결 안 된 항목은 "연결 전"으로 표시되며, 연결되는 대로 계산에 들어갑니다.

사업자매출마켓 수수료도매 원가광고비배송비순이익
항목별 데이터 출처
  • 마켓 수수료 — 쿠팡·G마켓·옥션은 정산 API, 11번가·롯데ON은 정산 엑셀 업로드
  • 도매 원가 — 도매꾹(위탁) 발주 기록(발주 엑셀·원가 비교 결과)
  • 광고비 — 쿠팡 광고센터 광고보고서 엑셀 업로드(쿠팡은 광고 API 없음)
  • 배송비 — 위탁 발주 시 공급사 배송비
